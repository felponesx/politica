Fluxos e estrutura

        

          
Cadastrar um vínculo e seus links

          
Bots → Vínculos → + Novo vínculo → arquivo vinculos/<produto>.toml no GitHub → o celular recebe

          
Captação automática

          
celular (cron, a cada 5 min) → coletar (só as vencidas) → verificar (Gemini) → publicar

          
O que chega ao sistema

          
dado novo → corretor → liberado: publicado · suspeito: retido (o último dado bom segue publicado)

Como funciona

        

          
Depois de cada coleta, o dado novo passa por regras locais (arquivo vazio, JSON quebrado, tamanho muito diferente do último dado bom) e, se houver chave, pelo Gemini, que lê uma amostra e diz se está coerente com o que a fonte promete.

          
Dado correto é publicado. Dado suspeito ou com erro fica retido: o último dado bom continua publicado até você aprovar ou rejeitar.
